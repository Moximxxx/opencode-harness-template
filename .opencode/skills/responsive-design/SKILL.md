# Responsive Design Skill

## 断点设置（Mobile First）

| 名称 | 最小宽度 | 目标设备 |
|------|---------|---------|
| xs | 320px | 手机竖屏 |
| sm | 576px | 手机横屏 |
| md | 768px | 平板竖屏 |
| lg | 992px | 平板横屏 |
| xl | 1200px | 桌面 |

## 规则

- 使用 CSS 框架（如 Tailwind CSS）的响应式前缀
- 最小触摸目标: 44x44px
- 图片使用 srcset 适配
- 移动端优先设计
